Туннели

Импорт профиля

Выберите .vpn, .txt или .conf, либо вставьте ключ. Один профиль — одно устройство.

Для замены укажите существующее имя без .conf. Новый профиль добавляется при остановленной службе.

Импорт только IPv4. DNS роутера сохраняется. После замены проверьте связь с новым сервером.

Резервные копии

Копия создаётся перед заменой. Восстановление применяет её к прежнему профилю.

PingCheck

Проверка связи через VPN средствами прошивки. Ниже — текущее состояние, затем настройки новой проверки.

—

Поля содержат рекомендуемые значения для новой проверки, а не прочитанные настройки. Применение заменит назначенную проверку только выбранного VPN.

Режим ICMP, без перезапуска интерфейса. Переключение на провайдера зависит также от политик и маршрутов Netcraze.

Для сохранения после перезагрузки нажмите кнопку ниже. Она сохраняет всю текущую конфигурацию прошивки, включая изменения вне этой панели.

Журнал службы

Последние сообщения, с фильтрацией ключей. Профили здесь не отображаются.

Watchdog и папка приёма

Следит за локальным движком и обрабатывает новые файлы inbox примерно каждые 30 секунд, пока служба запущена.
