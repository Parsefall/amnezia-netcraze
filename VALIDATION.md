## Локальные проверки

Shell-парсер: IPv4 /0../32, CRLF, поля профиля, запрет shell-инъекций, сохранение результата при ошибке, аргументы DNS, текстовая ошибка NDMS при exit code 0, отсутствие автоматического default route даже при AllowedIPs=0.0.0.0/0.

Служба: ошибки awg/NDMS, стабильные номера, сохранение чужих интерфейсов, запрет repair после stop. Моки не заменяют испытания NDMS.

Пакет: allowlist файлов, ELF64 AArch64, отсутствие динамического загрузчика у AWG-Go, сверка бинарников с BUILD-INFO, SHA256 каждого файла и содержимого tar.gz.

## Исправление S4

Официальный amneziawg-go v3.1.20260828, commit b5928efb6ca19f0153958460c3d141f04abc5c2e, собран Go 1.25.14, CGO_ENABLED=0, linux/arm64. Единственный локальный патч: build/patches/002-go-tun-padding-refresh.patch.

RoutineReadFromTUN читал S4 до блокирующего Read. При изменении S4 во время ожидания первый payload мог использовать старый отступ. Патч повторно читает отступ после Read, проверяет размер и перемещает payload с поддержкой перекрытия. Криптоалгоритмы не меняются.

До патча отказ воспроизводился в TestAWGDevicePing и дополнительном тесте. После патча прошли device/conn/replay/tai64n и 10 повторов TestRouterAWG31Profile (in-memory/UDP), TestRouterS4ChangeWhileReadBlocked и TestAWGDevicePing: 70 результатов тестов/подтестов, 0 ошибок. Регрессия включена в tests/go_profile_smoke_test.go; это тесты Windows, не измерение скорости роутера.

Не проверены: IPv6, все AWG-параметры во всех комбинациях, длительная стабильность, предел скорости, Docker-путь сборки, резервирование при реальном сбое. CLI awg унаследован из исходного проекта; версия и запуск проверены, побитовая воспроизводимость сборки не установлена.

## Конвертер 0.2.0

14 автоматических тестов на синтетических ключах: экспорт qCompress/Base64URL и JSON, сохранение параметров AWG, явная обработка IPv6, повреждённые и чрезмерно большие данные, несколько профилей, отсутствие клиентской конфигурации, приватное создание без перезаписи и CLI. Выходной профиль дополнительно проверен реальным shell-парсером проекта. Новый конвертер пока не проверялся на реальном .vpn пользователя; ручная проверка GUI не проведена. Это не меняет статус проверок VPN-движка и отказоустойчивости.
