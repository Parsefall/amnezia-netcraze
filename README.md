# Amnezia Netcraze

**Русский** | [English](README.en.md)

Amnezia VPN на роутере с удобной веб-панелью. Управляйте VPN с компьютера или телефона: добавляйте подключения, меняйте ключи и следите за состоянием туннелей прямо в браузере. Приложение работает на самом роутере.

## Возможности

- **Простая настройка:** создайте клиентский профиль AmneziaWG в Amnezia, затем загрузите его экспорт `.vpn`/`.txt` или вставьте полный клиентский ключ в панель.
- **Несколько VPN-туннелей:** создавайте, переименовывайте, запускайте, приостанавливайте и удаляйте подключения. У каждого туннеля свои настройки.
- **Контроль соединения:** просматривайте состояние туннелей и настраивайте PingCheck.
- **Автозапуск и восстановление:** запускайте VPN после перезагрузки роутера и используйте watchdog для восстановления переставшего отвечать локального движка.
- **Удобное обслуживание:** просматривайте журнал, заменяйте ключ нужного туннеля и устанавливайте совместимые обновления с GitHub через панель.
- **Русский и английский интерфейс.**

[Инструкция по установке](INSTALL.md) · [Руководство по панели](docs/WEB.md) · [Скачать](https://github.com/Parsefall/amnezia-netcraze/releases/latest)

**Проверено ТОЛЬКО на конкретном Netcraze Giga NC-1012 владельца проекта:** аппаратная ревизия `1210C000`, ARM64 (`aarch64`), прошивка **5.1.5 / 5.01.C.5.0-0**, Linux **4.9-ndm-5**, Entware на накопителе и `/dev/net/tun`. Совместимость с другими моделями и прошивками не заявляется.

## Скачать и установить

1. Скачайте `awg3-netcraze-arm64-userspace.tar.gz` и `.sha256` из [Releases](https://github.com/Parsefall/amnezia-netcraze/releases/latest).
2. Создайте **отдельного клиента Amnezia для роутера**. Один профиль нельзя одновременно использовать на ПК и роутере.
3. Выполните [пошаговую установку](INSTALL.md): установите VPN и панель, затем загрузите `.vpn`/`.txt` или вставьте ключ в **«Туннели → Добавить туннель»**.
4. Выберите [схему маршрутизации](docs/ROUTING.md).
5. Настройте [Ping Check](docs/HEALTHCHECK.md), проверьте работу и включите автозапуск.

## Системные требования

- Роутер с 64-битной архитектурой ARM (`aarch64`), Entware в `/opt` и root-доступом к его SSH shell.
- Устройство TUN `/dev/net/tun`, команды `ndmc` и поддержка интерфейсов `OpkgTun` в прошивке; компонент Ping Check для контроля доступности.
- Совместимые системные библиотеки для `awg`: загрузчик `/lib/ld-musl-aarch64.so.1`, libc и libgcc. Пакет не подходит для MIPS/MIPSEL и 32-битного ARM.
- Python **3.10 или новее**, пакеты Python для HTTPS-панели, `openssl-util` и `ca-bundle`. Команды установки зависимостей приведены в [инструкции](INSTALL.md).
- Свободное место на накопителе для приложения, зависимостей и резервных копий. Для обновления через панель требуется не менее **48 МиБ свободного места** перед загрузкой; место под резервную копию проверяется дополнительно.
- Запас свободной оперативной памяти под VPN и панель. На тестовом роутере **512 МиБ ОЗУ**; это характеристика проверенного устройства, а не установленный минимальный объём. Расход памяти растёт с количеством туннелей.
- Браузер с JavaScript и доступом к локальной сети роутера.

## Ограничения

- Один peer и один IPv4-адрес на профиль. IPv6 через VPN не настраивается.
- AllowedIPs задаёт допустимые адреса внутри AWG, а не создаёт маршруты NDMS.
- Это маршрутизация устройств и IP, а не отдельных приложений Windows.
- Watchdog следит за локальным процессом, а Ping Check — за передачей трафика. Это разные задачи.
