# Установка Amnezia Netcraze

**Русский** | [English](INSTALL.en.md)

Установите приложение на роутер, откройте веб-панель и добавьте клиентский профиль AmneziaWG: загрузите файл экспорта или вставьте полный ключ.

## 1. Подготовка

Нужны ARM64 (`aarch64`), установленный Entware в `/opt`, root-доступ к его SSH shell и `/dev/net/tun`. Проверенная конфигурация: Netcraze Giga NC-1012, hw 1210C000, NetcrazeOS 5.1.5, ядро 4.9-ndm-5. Другие модели не проверены. Первоначальная установка Entware в эту инструкцию не входит.

Сохраните конфигурацию роутера и оставьте провайдера первым в основной политике до проверки VPN.

Создайте в Amnezia **отдельного клиента AmneziaWG для роутера**. Подготовьте один из вариантов:

- гостевой файл `.vpn` со встроенной клиентской конфигурацией AmneziaWG;
- файл `.txt` с полным ключом `vpn://…` такого клиента;
- сам полный ключ `vpn://…`, который можно вставить в панель.

Нативный `.conf` также принимается, если он уже есть, но получать его специально не требуется. Один клиентский ключ нельзя одновременно использовать на ПК и роутере или в нескольких туннелях.

Не любой ключ Amnezia содержит конфигурацию: ключ подписки, административный экспорт без клиентского профиля или один PrivateKey не подходят. Если приложение сообщает об отсутствии AWG-профиля, получите клиентский экспорт AmneziaWG у владельца сервера/провайдера. Автоматическое получение конфигураций по подписке не реализовано. Переименовывать `.vpn` в `.conf` не нужно.

## 2. Скачать и скопировать пакет

Скачайте `awg3-netcraze-arm64-userspace.tar.gz` и его `.sha256` из [последнего релиза](https://github.com/Parsefall/amnezia-netcraze/releases/latest).

В **PowerShell на компьютере**, из папки со скачанным архивом:

```powershell
Get-FileHash .\awg3-netcraze-arm64-userspace.tar.gz -Algorithm SHA256
Get-Content .\awg3-netcraze-arm64-userspace.tar.gz.sha256
```

Сравните значения SHA256; продолжайте при совпадении.

```powershell
scp -O -P 22 .\awg3-netcraze-arm64-userspace.tar.gz root@192.168.1.1:/opt/tmp/
ssh -p 22 root@192.168.1.1
```

Замените IP и SSH-порт на свои при необходимости. Нужен shell Entware (`~ #`), а не CLI прошивки.

## 3. Установить VPN и панель

Команды ниже предназначены для **первой установки**, выполняются в **SSH роутера**. Для уже установленного проекта см. раздел обновления ниже.

```sh
opkg update
opkg install python3-light python3-codecs python3-openssl python3-email python3-urllib python3-logging openssl-util ca-bundle
mkdir -p /opt/tmp/awg3-setup
tar -xzf /opt/tmp/awg3-netcraze-arm64-userspace.tar.gz -C /opt/tmp/awg3-setup
cd /opt/tmp/awg3-setup/awg3-userspace
sh router/install.sh
sh router/install-web.sh
```

Продолжайте только при успешном завершении каждой команды. Установщики проверяют внутренние контрольные суммы. На этом этапе VPN ещё не запущен, профиль не импортирован, маршруты не изменены.

Задайте пароль панели и параметры своей домашней сети:

```sh
/opt/bin/python3 /opt/lib/awg3/web/server.py --setup --bind 192.168.1.1 --network 192.168.1.0/24 --port 8088
/opt/etc/init.d/S101awg3-web enable
```

Если адрес или подсеть другие — замените их. Пароль панели отдельный, 12–128 символов; вводится скрыто дважды. Запишите выведенный отпечаток сертификата.

## 4. Добавить туннель в браузере

1. Откройте **http://192.168.1.1:8088** или **https://192.168.1.1:8088** из домашней сети. HTTP передаёт пароль и профили без шифрования. Самоподписанный сертификат вызовет предупреждение; сверьте отпечаток с выведенным при настройке. Подробнее — [веб-панель](docs/WEB.md).
2. Войдите с заданным паролем.
3. Откройте **«Туннели → Добавить туннель»**.
4. Задайте уникальное имя латиницей, выберите `.vpn`/`.txt` **или** вставьте полный ключ.
5. Нажмите **«Создать и запустить»**.

Приложение проверит экспорт, преобразует его и сохранит внутреннюю конфигурацию с ограниченными правами. Вручную создавать или редактировать `.conf` не требуется. Дополнительные туннели добавляются так же, каждый со своим клиентским ключом.

## 5. Маршруты, проверка и автозапуск

Создание туннеля не направляет в него весь интернет автоматически. Выберите [схему маршрутизации](docs/ROUTING.md) в штатном интерфейсе роутера.

В настройках конкретного туннеля (⚙) включите [PingCheck](docs/HEALTHCHECK.md). Проверьте состояние, внешний IP и открытие сайтов на устройстве, которому назначена VPN-маршрутизация, с отключённым VPN на самом устройстве.

В «Настройках» панели включите автозапуск VPN. Он общий; отдельно приостановленные туннели останутся приостановленными. Watchdog включается отдельно и восстанавливает локальный движок, а PingCheck проверяет доступность через туннель. Реальное резервирование при отказе на тестовом устройстве ещё не испытано.

Сохраните конфигурацию прошивки после изменения маршрутов и PingCheck. Кнопка сохранения PingCheck сохраняет **всю текущую конфигурацию роутера**, включая другие несохранённые изменения. После перезагрузки повторно проверьте связь. Панель имеет собственный автозапуск.

## Замена ключа или сервера

Откройте **«Туннели → ⚙ нужного туннеля → Заменить ключ VPN»**, загрузите новый `.vpn`/`.txt` либо вставьте ключ и нажмите «Проверить и применить». Не создавайте новый туннель, если нужно сохранить привязку существующего к маршрутам и политикам.

Имя интерфейса и его привязки сохраняются; проверьте связь после замены. Если вручную создавали маршрут к старому адресу VPN-сервера, обновите его отдельно. Новый профиль должен разрешать нужные адреса в AllowedIPs.

## Обновление приложения

С v0.8.0: **«Настройки → Обновление приложения → Проверить → Обновить»**. Роутер сам загружает совместимый релиз, проверяет его и создаёт резервную копию. После перезапуска панели войдите снова. Подробнее об откате и ограничениях — [обновление панели](docs/WEB.md).

Для старой версии панели: скопируйте и распакуйте новый пакет, установите зависимости из шага 3, выполните **только `sh router/install-web.sh`**, затем Ctrl+F5 в браузере. Пароль, сертификат и профили сохраняются; повторный `--setup` не нужен.

Если релиз меняет бинарники VPN, кнопка потребует ручное обновление. Сначала верните клиентов на провайдера и сохраните профили и настройки. Выполните `/opt/etc/init.d/S99awg3 disable`, затем перезагрузите роутер: остановка службы оставляет процессы TUN, а установщик не заменяет работающий движок. После перезагрузки повторите оба установщика, проверьте маршруты, запустите нужные туннели и снова включите автозапуск.

## Дополнительные способы и удаление

[Импорт через SSH/inbox](docs/ROUTER-IMPORT.md) и [офлайн-конвертер на ПК](docs/CONVERTER.md) остаются дополнительными инструментами, для установки через панель они не нужны.

Для удаления верните клиентов на провайдера и отключите свои VPN-маршруты. Выполните `/opt/etc/init.d/S99awg3 disable`, затем `/opt/etc/init.d/S99awg3 stop`. `sh router/uninstall.sh` из пакета сохраняет профили, бинарники, резервные копии и объекты NDMS; это не полный откат сетевой конфигурации. Не возвращайте старый несовместимый `amneziawg.ko`.
