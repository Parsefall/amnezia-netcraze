# Установка Amnezia Netcraze

**Русский** | [English](INSTALL.en.md)

## Подготовка

Нужны установленный Entware, доступ root к его shell, накопитель с `/opt` и `/dev/net/tun`. Проверенная модель и прошивка указаны в [README](README.md). Это не инструкция по первоначальной настройке Entware.

Сохраните резервную копию конфигурации роутера через веб-интерфейс. Оставьте провайдера первым в политике по умолчанию. Для восстановления используйте локальный адрес роутера.

Создайте на VPN-сервере **отдельного клиента для роутера**, экспортируйте AmneziaWG `.conf`. Не копируйте активный профиль Windows: при одинаковых ключах сервер может переключать адрес доставки между устройствами. Личные профили никогда не публикуйте.

Примеры используют `192.168.1.1` и SSH **22** — они работали на тестовом роутере. Если Entware SSH у вас на другом порту, замените `22`. В SCP порт задаётся большой `-P`, в SSH маленькой `-p`. Подключение должно открывать shell с приглашением `~ #`, а не только CLI прошивки.

## 0. Если на руках только ключ Amnezia

Установщику нужен **полный конфигурационный файл AmneziaWG `.conf`**, а не строка `vpn://…`, файл `.vpn`, QR-код или отдельный PrivateKey. Переименование `.vpn` в `.conf` не преобразует формат. Автоматического декодирования ключей в этом проекте нет.

### Свой сервер Amnezia

1. Откройте AmneziaVPN с подключением, имеющим полный доступ к вашему серверу.
2. Откройте «Поделиться VPN», создайте отдельного пользователя для роутера и выберите протокол **AmneziaWG**.
3. Выберите **нативный/оригинальный формат AmneziaWG** (AmneziaWG native format), а не «Для приложения AmneziaVPN». Названия пунктов могут отличаться по версии приложения.
4. Сохраните `.conf` (например, `amnezia_for_awg.conf`) и переименуйте копию в `router.conf` для команд этой инструкции.

Если другой человек выдал вам только гостевой `vpn://`-ключ, попросите его выдать **отдельный профиль AmneziaWG в нативном формате для роутера**. Наличие ключа само по себе не означает наличие прав экспорта или управления сервером.

[Официальная инструкция экспорта](https://docs.amnezia.org/documentation/instructions/amnezia-hosting-sharing/).

### Amnezia Premium

Откройте личный кабинет по ссылке из официального письма/приложения, войдите своим ключом подписки, найдите раздел конфигурационных файлов и скачайте `.conf` для нужной локации. Создание конфигурации занимает слот подключения. Обычный ключ подписки нельзя просто вставить в router.conf.

Документация Amnezia указывает для этих файлов AWG 3.1, однако **работа именно Amnezia Premium с данным проектом отдельно не проверялась**. Автообновление подписки здесь не реализовано: при отзыве или изменении конфигурации потребуется новый файл.

[Официальная инструкция личного кабинета](https://docs.amnezia.org/documentation/instructions/personal_dashboard/).

### Как убедиться, что файл подходит

Откройте файл локально, не публикуя содержимое. Ожидаются разделы `[Interface]` и `[Peer]`, параметры Address, PrivateKey, PublicKey, AllowedIPs и Endpoint, а также выданные сервером параметры AmneziaWG. В одном файле нужны все параметры, а не только ключ. Наличие этих названий не заменяет проверку профиля парсером и сервером.

Конфигурации VLESS/XRay/OpenVPN и другие форматы этот установщик не принимает. IPv4-ограничения и подготовка копии описаны в шаге 3. Получив подходящий router.conf, переходите к шагу 1.

## 1. Скачать и проверить — PowerShell Windows

Скачайте архив и `.sha256` из [релиза](https://github.com/Parsefall/amnezia-netcraze/releases/latest) в одну папку. Откройте PowerShell **в этой папке** (`PS C:\...>`):

```powershell
$expected = ((Get-Content .\awg3-netcraze-arm64-userspace.tar.gz.sha256 -Raw).Trim() -split '\s+')[0]
$actual = (Get-FileHash .\awg3-netcraze-arm64-userspace.tar.gz -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw 'Контрольная сумма не совпадает. Не устанавливайте архив.' }
scp -O -P 22 .\awg3-netcraze-arm64-userspace.tar.gz root@192.168.1.1:/opt/tmp/
ssh -p 22 root@192.168.1.1
```

`-O` включает старый протокол SCP: SFTP в Entware может отсутствовать. Пароль при вводе не отображается.

## 2. Установить — SSH роутера

Выполняйте по порядку. При ошибке остановитесь.

```sh
mkdir -p /opt/tmp/awg3-install
tar -xzf /opt/tmp/awg3-netcraze-arm64-userspace.tar.gz -C /opt/tmp/awg3-install
cd /opt/tmp/awg3-install/awg3-userspace
sh router/install.sh
```

Установщик проверит файлы и обе ARM64-программы. Старые файлы сохраняются в `/opt/etc/awg3/backups/<дата-PID>`. Это backup файлов проекта, а не всей NDMS-конфигурации. Автозапуск после установки выключен. Профили существующей установки сохраняются.

`amneziawg-go --version` может вывести `0.0.20250522`: это константа официальных исходников. Реальный тег, commit и SHA256 находятся в `prebuilt/kn-1012/BUILD-INFO.json`.

## 3. Скопировать свой профиль — PowerShell Windows

Откройте вторую вкладку PowerShell **без SSH**. Пример предполагает `router.conf` в текущей папке:

```powershell
scp -O -P 22 .\router.conf root@192.168.1.1:/opt/etc/awg3/conf/router.conf
```

Имя содержит только латинские буквы, цифры, `_`, `-`, `.` и заканчивается на `.conf`. В каталоге активны все файлы `.conf`; образец туда копировать не нужно.

Поддерживаются один IPv4 Address, IPv4 DNS и один peer. Если AllowedIPs содержит `::/0`, сделайте отдельную копию с помощью Python и скачанных исходников проекта:

```powershell
python build/prepare_profile.py original.conf router.conf --ipv4-only
```

Утилита убирает IPv6 только из AllowedIPs; IPv6 в Address/DNS требует отдельного корректного IPv4-профиля. Ключи, Endpoint и параметры обфускации нельзя придумывать или заменять примером.

## 4. Запустить — SSH роутера

```sh
chmod 600 /opt/etc/awg3/conf/router.conf
/opt/etc/init.d/S99awg3 up
/opt/etc/init.d/S99awg3 status
```

Запомните назначенный `OpkgTunN` / `opkgtunN`: это не всегда номер 0. Подключение в веб-интерфейсе называется по файлу — здесь `router`. Дождитесь handshake. «Подключено» ещё не доказывает доступ к Интернету.

## 5. Настроить маршруты и проверить компьютер

Выберите **одну** схему в [ROUTING.md](docs/ROUTING.md):

- Выборочные IP через VPN: провайдер первый, статические маршруты на VPN, без default route через VPN.
- Всё устройство через VPN: отдельная политика и явно добавленный default route туннеля; сначала только одно тестовое устройство.

При проверке отключите VPN-приложение на компьютере. Проверьте HTTPS и внешний IPv4 на выбранном пути. Команды Windows выполняются в PowerShell, не в SSH. Затем настройте [Ping Check](docs/HEALTHCHECK.md).

## 6. Сохранить и включить автозапуск — SSH

Только после успешной проверки:

```sh
/opt/etc/init.d/S99awg3 save
/opt/etc/init.d/S99awg3 enable
```

`Saving (cli)` означает источник команды. Сохраняется текущая конфигурация NDMS. Флаг автозапуска отдельно хранится на `/opt`.

Перезагрузите в удобное время и повторите status, DNS, HTTPS, внешний IP. Если связь пропала, через локальный веб-интерфейс верните провайдера первым, а компьютер — в политику по умолчанию. SSH после reboot подключается заново.

## Обновление

Верните клиентов на провайдера. Сохраните ключи, маршруты и managed.tsv.

```sh
/opt/etc/init.d/S99awg3 disable
```

Перезагрузите: stop сохраняет процессы TUN, установщик не заменяет работающий движок. После загрузки повторите установку, ручной запуск, проверку и enable/save. Старые маршруты установщик не удаляет: проверьте оставшийся `По умолчанию → VPN`. Релиз 0.1.0 больше не создаёт его автоматически.

Ping Check сохраняется в NDMS независимо от пакета. Опциональный UAPI-watchdog включается отдельно, не заменяет Ping Check и для первого запуска не требуется.

## Удаление и откат

Верните клиентов в политику провайдера, отключите свои VPN-маршруты, выполните `/opt/etc/init.d/S99awg3 disable`. Из распакованного архива можно выполнить `sh router/uninstall.sh`: он сохраняет профили, бинарники, backup и NDMS-объекты. Это не полный сетевой rollback. Для замены файлов из backup сначала disable и reboot. Не возвращайте старый несовместимый `amneziawg.ko`.
