# Интеграция с маршрутизацией роутера

**Русский** | [English](ROUTING.en.md)

Приложение создаёт отдельный интерфейс `OpkgTunN` для каждого туннеля. Его можно использовать в штатных настройках подключений, маршрутов и политик доступа роутера.

Создание и запуск туннеля не назначают ему устройства и не добавляют маршрут по умолчанию. Выберите нужный туннель в интерфейсе прошивки и настройте использование подключения средствами роутера. Поле AllowedIPs в профиле AmneziaWG не заменяет настройку маршрутизации прошивки.

Замена ключа в настройках существующего туннеля сохраняет его идентификатор и привязки. После удаления туннеля проверьте связанные с ним настройки прошивки. После изменения сетевой конфигурации сохраните её средствами роутера.

Приложение работает с IPv4; маршрутизация IPv6 через VPN не реализована. Настройки DNS из импортируемого через панель экспорта не применяются автоматически.

Для контроля связи настройте [PingCheck](HEALTHCHECK.md) отдельно для каждого туннеля. Резервирование зависит также от политик прошивки: состояние PingCheck само по себе не подтверждает, что переключение на другое подключение проверено.
