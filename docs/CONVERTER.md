# Конвертер .vpn / vpn:// → router.conf

Это дополнительный инструмент для работы на ПК. При установке через [веб-панель](../INSTALL.md) он не нужен: `.vpn`/`.txt` и ключи импортируются непосредственно в браузере.

**Русский** | [English](CONVERTER.en.md)

Хотите обойтись без конвертации на ПК? [Роутерный импорт](ROUTER-IMPORT.md) принимает файл .vpn или .txt и умеет автоматически заменять существующий профиль.

Конвертер работает **локально, без сети**. Он извлекает существующий клиентский профиль AmneziaWG из гостевого экспорта Amnezia. Секреты не отправляются на сайт, не выводятся в консоль и не передаются аргументом командной строки.

## Проще всего — Windows

1. Скачайте `amnezia-netcraze-converter.zip` из [последнего релиза](https://github.com/Parsefall/amnezia-netcraze/releases/latest) и распакуйте целиком. Конвертер также включён в установочный tar.gz.
2. Нужен **Python 3.10+ с tkinter**. Стандартный установщик Python для Windows позволяет установить Tcl/Tk; сторонние Python-пакеты и pip не нужны.
3. Дважды щёлкните `convert-profile.cmd`.
4. Выберите файл `.vpn` **или** вставьте ключ `vpn://…` в окно. Не выбирайте оба источника одновременно.
5. Для этого роутера оставьте отмеченным «Только IPv4» и нажмите «Сохранить router.conf». Выберите новое имя, если такой файл уже существует.
6. Скопируйте полученный файл на роутер по шагу 3 [инструкции установки](https://github.com/Parsefall/amnezia-netcraze/blob/main/INSTALL.md).

Английский интерфейс: `python tools/convert_profile.py --gui --lang en`. При отсутствии tkinter можно использовать CLI. На Windows приватность файла определяется также правами папки: сохраняйте его в своей локальной папке, не в общей/синхронизируемой.

## Командная строка

PowerShell или терминал ПК, из распакованной папки:

```powershell
python tools/convert_profile.py --input amnezia_config.vpn --output router.conf --ipv4-only
```

Если есть только строка ключа:

```powershell
python tools/convert_profile.py --paste --output router.conf --ipv4-only
```

Вставьте ключ **в приглашение программы**, а не в команду: ввод скрыт. Вместо этого можно сохранить строку в локальный `.txt` и передать через --input. При нескольких встроенных AWG-профилях нужен --profile-index N (нумерация с 1); GUI просит экспортировать один профиль или использовать CLI. По умолчанию профиль при неоднозначности не выбирается.

## Какие данные поддерживаются

- `.vpn`, содержащий `vpn://` с Base64URL и Qt qCompress (4-байтовая длина + zlib), и тот же ключ текстом.
- Несжатый JSON, Base64 JSON и бинарный qCompress экспорт.
- `containers[].awg.last_config` (JSON-строка или объект) с полным нативным `config`.
- Уже готовый нативный `.conf` для проверки и подготовки IPv4-копии.

Все выданные AWG-параметры, включая I1–I5 и HeaderProtectionKey, сохраняются. Проверяются обязательные поля, структура, ключи, адреса, Endpoint и совместимость с обвязкой; окончательная проверка параметров протокола остаётся за awg. Shell-хуки PostUp и неизвестные поля не исполняются и не принимаются. Комментарии не копируются, чтобы не переносить ключ подписки из метаданных.

Опция --ipv4-only явно удаляет IPv6 из Address, DNS и AllowedIPs. Требуются один IPv4 Address и хотя бы один IPv4 AllowedIPs; если DNS был только IPv6, он удаляется. Без опции IPv6 вызывает ошибку. Маршруты роутера эта программа не меняет и не преобразует AWG 2.0 в 3.1.

## Что нельзя извлечь офлайн

**Не каждый ключ содержит клиентский профиль.** Ключ подписки/API Premium может содержать только данные доступа к сервису; ключ полного управления сервером может не содержать клиентских ключей. В таких случаях программа завершится с объяснением: скачайте `.conf` из личного кабинета либо создайте отдельный гостевой AWG-профиль в AmneziaVPN. Конвертер не входит в личный кабинет и не подключается по SSH к серверу.

Конфигурации других протоколов, многопировые и повреждённые файлы отклоняются. Распаковка ограничена по размеру. Источник не меняется; существующий выходной файл не перезаписывается. На POSIX новый файл создаётся с правами 0600.

**Конвертация не создаёт нового клиента или новых ключей.** Нельзя одновременно использовать исходный профиль на ПК и его конвертированную копию на роутере. Сначала создайте отдельный гостевой доступ для роутера.

Реализация формата сверена с [официальным exportController](https://github.com/amnezia-vpn/amnezia-client/blob/94b51df24790bf52427afe82d81c87a95460bdfd/client/core/controllers/selfhosted/exportController.cpp) и [AwgProtocolConfig](https://github.com/amnezia-vpn/amnezia-client/blob/94b51df24790bf52427afe82d81c87a95460bdfd/client/core/models/protocols/awgProtocolConfig.cpp). Тесты используют синтетические профили; реальный файл пользователя этой версией конвертера пока не проверен. Графическое окно отдельно вручную не испытано.
