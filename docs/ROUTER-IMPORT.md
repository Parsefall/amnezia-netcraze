# Импорт .vpn и ключей прямо на роутере

**Русский** | [English](ROUTER-IMPORT.en.md)

Начиная с v0.3.0 можно менять сервер/клиента, загружая новый экспорт Amnezia в существующий профиль. Имя профиля связывает файл с тем же OpkgTun: политики, маршруты, PingCheck и приоритет интерфейса сохраняются. Новая серверная конфигурация должна по-прежнему разрешать нужные адреса в AllowedIPs. Это не перенос настроек самого сервера.

Поддерживаются гостевые экспорты AmneziaWG `.vpn` и `.txt`, содержащие ключ `vpn://` и полный клиентский профиль. Подписки/API и административные экспорты без клиентской конфигурации требуют отдельного экспорта; форматные ограничения описаны в [конвертере](CONVERTER.md). Преобразование локальное, ключ никуда не отправляется. Один клиент — одно устройство.

## Один раз: установить поддержку

В SSH shell Entware:

```sh
opkg update
opkg install python3-light python3-codecs
/opt/bin/python3 -c 'import argparse, base64, getpass, ipaddress, json, pathlib, zlib; print("Python modules OK")'
```

Нужен Python 3.10+. Используются пакеты [официального репозитория Entware ARM64](https://bin.entware.net/aarch64-k3.10/). Python запускается только во время конвертации и завершается; постоянного Python-процесса нет. Дополнительное потребление памяти на реальном роутере пока не измерено.

Для новой установки следуйте [INSTALL](../INSTALL.md). Установщик уже размещает конвертер. Вместо ручной подготовки `.conf` можно скопировать экспорт в `/opt/tmp/new.vpn` и выполнить:

```sh
/opt/etc/init.d/S99awg3 import /opt/tmp/new.vpn router
/opt/etc/init.d/S99awg3 up
```

На остановленной службе импорт только сохраняет `router.conf`; запуск остаётся отдельным действием. Затем настройте маршрутизацию и PingCheck по основным инструкциям.

### Обновление уже работающей версии 0.1/0.2

Скачайте установочный архив v0.3.0 или новее из [релиза](https://github.com/Parsefall/amnezia-netcraze/releases/latest), скопируйте в `/opt/tmp` и распакуйте в новую пустую папку. Например:

```sh
mkdir -p /opt/tmp/awg3-v030
tar -xzf /opt/tmp/awg3-netcraze-arm64-userspace.tar.gz -C /opt/tmp/awg3-v030
sh /opt/tmp/awg3-v030/awg3-userspace/router/update-importer.sh
```

Этот отдельный обновлятор проверяет суммы пакета, сохраняет копии скриптов и заменяет только службу, watchdog, парсер и конвертер. Движок VPN, профили и флаги автозапуска не заменяет. Профили не применяются заново при обновлении. Обычный `install.sh` для горячего обновления не используйте: он требует остановленных процессов.

Обновление скриптов и импорт проверены тестами с имитацией роутера, **на физическом NC-1012 новая процедура ещё не проверена**. Используйте локальный SSH и сохраняйте возможность вернуть провайдера первым через веб-интерфейс.

## Замена профиля одной командой

Посмотрите текущие имена:

```sh
/opt/etc/init.d/S99awg3 status
```

Если там `OpkgTun0 <- router.conf`, после загрузки нового файла выполните:

```sh
/opt/etc/init.d/S99awg3 import /opt/tmp/new.vpn router
```

Для ключа в текстовом файле:

```sh
/opt/etc/init.d/S99awg3 import /opt/tmp/new.txt router
```

Последний аргумент — **существующее имя без .conf**. Например, для `pars.conf` используйте `pars`, а не `router`: иначе получится другой профиль. При запущенной службе неизвестное имя отклоняется. Прежняя копия сохраняется в `/opt/etc/awg3/backups/imports/`.

## Автоматически: загрузить и переименовать

Один раз включите watchdog:

```sh
/opt/etc/init.d/S100awg3-watchdog enable
```

Он проверяет входящую папку примерно раз в 30 секунд, пока VPN-служба запущена. Служба также обрабатывает папку при автозапуске. Остановка VPN отключает фоновую обработку; импорт не включает остановленный VPN самовольно.

Пример для `router.conf`, PowerShell на компьютере:

```powershell
scp -O -P 22 "C:\Users\you\Downloads\new.vpn" root@192.168.1.1:/opt/etc/awg3/inbox/router.vpn.part
ssh -p 22 root@192.168.1.1 'mv /opt/etc/awg3/inbox/router.vpn.part /opt/etc/awg3/inbox/router.vpn'
```

Для текстового ключа замените `.vpn` на `.txt` в обеих командах. Для `pars.conf` замените `router` в имени файла назначения на `pars`. В SFTP-клиенте можно так же загрузить `.part` и переименовать после окончания передачи. **Не загружайте сразу в конечное имя**: обработчик может увидеть неполный файл. Не отправляйте одновременно `.vpn` и `.txt` для одного профиля.

Обработанные файлы перемещаются в приватные `/opt/etc/awg3/inbox/item.*/`; рядом создаётся `result` с результатом. Ошибочные файлы не запускаются по кругу. Неизвестное имя остаётся в inbox без применения. Резервные копии и исходные экспорты содержат секреты: не публикуйте их, удаляйте ненужные вручную.

```sh
cat /opt/etc/awg3/inbox/item.*/result
/opt/etc/init.d/S99awg3 status
ndmc -c "show ping-check"
```

## Что сохраняется и что проверяется

- Конвертер и роутерный парсер проверяют файл до изменения профиля. IPv6 удаляется явно в режиме роутерного импорта; требуется IPv4.
- Меняются клиентские ключи, peer, Endpoint, Address и AWG-параметры. DNS из экспорта не применяется: используются настройки DNS прошивки. MTU без явного значения становится 1280.
- Существующий OpkgTun не удаляется, его приоритет и маршруты не переписываются. Повторный запуск теперь также не задаёт `ip global auto` уже существующим интерфейсам.
- Если движок или NDMS отклоняет применение, восстанавливается старый файл и выполняется попытка применить старую конфигурацию. Ошибка самого отката явно сообщается; это не гарантия отката при отключении питания или SIGKILL.
- Успешное применение **не доказывает доступность сервера**. Проверьте свежий handshake и трафик. Для резервирования нужен [PingCheck](HEALTHCHECK.md); реальное переключение пока не испытано.
- Файл профиля сохраняется на накопителе. Импорт не выполняет `system configuration save`: при следующем запуске адрес снова применяется из профиля. Настройки политик/PingCheck сохраняйте отдельно.
- При смене Endpoint вручную созданный маршрут до старого сервера не обновляется. Проверьте, что новый Endpoint достигается через провайдера, особенно при VPN первым: `ip -4 route get НОВЫЙ_IP`. Автоматическое управление такими исключениями не реализовано.

Для ручного отката скопируйте нужную приватную резервную копию в `/opt/tmp/old.conf`, затем выполните `S99awg3 import /opt/tmp/old.conf router` с полным путём к службе и правильным именем профиля. Автоматическая папка принимает только `.vpn` и `.txt`; явная команда принимает также native `.conf`.
