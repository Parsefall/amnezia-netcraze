# Веб-панель на роутере

**Русский** | [English](WEB.en.md)

Панель v0.4.0 работает на **самом роутере** через Entware. Компьютер/телефон нужен только как браузер. Это отдельный адрес HTTPS, а не карточка встроенного раздела «Приложения» Netcraze. В интерфейсе есть русский и английский языки.

Возможности: импорт .vpn/.txt/.conf или ключа, замена существующего профиля, запуск/остановка всей VPN-службы, автозапуск, watchdog/inbox, время handshake, счётчики трафика, просмотр PingCheck, фильтрованный журнал, восстановление резервной копии, смена пароля панели. Маршруты, политики устройств и настройка PingCheck остаются в штатном интерфейсе прошивки.

## Установка поверх работающего проекта

Требуются Entware и уже установленный Amnezia Netcraze. Для нового роутера сначала выполните [установку VPN](../INSTALL.md); импорт профиля затем можно сделать через панель. Проверенная ранее аппаратная конфигурация: Netcraze Giga NC-1012, hw 1210C000, aarch64, NetcrazeOS 5.1.5, kernel 4.9-ndm-5. **Сама новая веб-панель на физическом роутере пока не проверена.**

1. Скачайте `awg3-netcraze-arm64-userspace.tar.gz` из [релиза v0.4.0](https://github.com/Parsefall/amnezia-netcraze/releases/tag/v0.4.0). В PowerShell на ПК, из папки с архивом:

```powershell
scp -O -P 22 .\awg3-netcraze-arm64-userspace.tar.gz root@192.168.1.1:/opt/tmp/
ssh -p 22 root@192.168.1.1
```

2. Далее **в SSH shell роутера**, не в PowerShell:

```sh
opkg update
opkg install python3-light python3-codecs python3-openssl python3-email python3-urllib python3-logging openssl-util
mkdir -p /opt/tmp/awg3-v040
tar -xzf /opt/tmp/awg3-netcraze-arm64-userspace.tar.gz -C /opt/tmp/awg3-v040
sh /opt/tmp/awg3-v040/awg3-userspace/router/install-web.sh
```

Пакеты Python разделены в [Entware ARM64](https://bin.entware.net/aarch64-k3.10/), поэтому одной установки python3-light для HTTPS-панели недостаточно. pip и сторонние Python-библиотеки не нужны. Установщик проверяет импорт модулей и контрольные суммы, обновляет скрипты импорта, сохраняет резервные копии, устанавливает панель. VPN-движок и существующие профили не заменяются, маршруты не меняются, VPN не перезапускается.

3. Задайте **свой пароль панели** (12–128 символов) и адрес домашней сети:

```sh
/opt/bin/python3 /opt/lib/awg3/web/server.py --setup --bind 192.168.1.1 --network 192.168.1.0/24 --port 8088
/opt/etc/init.d/S101awg3-web enable
```

Пароль вводится дважды скрыто; это отдельный пароль, не пароль root или веб-интерфейса Netcraze. Если LAN имеет другой адрес/маску, замените оба значения. Слушать `0.0.0.0` или публичный адрес запрещено. Порт 8088 должен быть свободен; при конфликте используйте другой порт выше 1023.

4. Откройте **https://192.168.1.1:8088**. Разрешён доступ с адресов указанной подсети. Вход по домену/CrazeDNS не поддерживается: проверяется точное соответствие IP и порта.

Сертификат создаётся локально и самоподписан, поэтому браузер покажет предупреждение о доверии. Сверьте SHA256-отпечаток сертификата с выведенным при настройке и доверяйте ему только при совпадении. Повторно вывести отпечаток:

```sh
/opt/bin/openssl x509 -in /opt/etc/awg3/web/cert.pem -noout -fingerprint -sha256
```

Панель предназначена для домашней сети: не настраивайте проброс порта/публичный reverse proxy. Фильтрация по подсети не заменяет разделение доверенных и гостевых устройств на самом роутере. Сертификат действует 825 дней; для перевыпуска повторите setup, задайте пароль и перезапустите панель.

## Обычная работа

- На вкладке «Профили» укажите существующее имя **без .conf** (например `pars` для `pars.conf`). Выберите файл или вставьте ключ и нажмите «Проверить и применить». В работающей службе неизвестное имя отклоняется; создание нового профиля доступно при остановленной службе.
- Импорт сохраняет OpkgTun, маршруты, политики и приоритет. Ограничения экспорта и поведение отката описаны в [роутерном импорте](ROUTER-IMPORT.md). DNS из профиля не применяется, IPv6 удаляется, отсутствующий MTU становится 1280.
- После переноса сервера проверьте новый handshake, PingCheck и трафик. Доступный движок не означает исправное VPN-соединение. Правило до старого Endpoint при наличии нужно обновить отдельно.
- Кнопки запуска и остановки управляют **всей службой**, не одним выбранным туннелем. «Выключить и остановить VPN» снимает автозапуск и останавливает службу.
- Восстановление резервной копии применяется к её прежнему профилю. Ключи и файлы резервных копий через панель не скачиваются.
- Журнал фильтрует строки с ключами и длинные строки, похожие на секреты; это диагностический просмотр, а не полный экспорт лога. Не публикуйте диагностику без собственной проверки.
- Панель имеет отдельный автозапуск; остановка VPN её не выключает. Сессия длится один час. Смена пароля завершает все сессии.

## Управление и восстановление доступа

```sh
/opt/etc/init.d/S101awg3-web status
/opt/etc/init.d/S101awg3-web restart
# Отключить только панель и её автозапуск:
/opt/etc/init.d/S101awg3-web disable
# Включить обратно:
/opt/etc/init.d/S101awg3-web enable
```

Забытый пароль/смена LAN: остановите панель, повторите `--setup` с нужным адресом и подсетью, затем запустите её через `enable`. Это перевыпускает сертификат. Обновление той же версии установщиком сохраняет существующие пароль и LAN-настройки. Конфигурация и приватный TLS-ключ лежат в `/opt/etc/awg3/web/`, журналы запуска — `/opt/var/log/awg3-web.log`. Не публикуйте папку web с настройками. Общий `uninstall.sh` отключает также панель, сохраняя данные.

## Проверки и ресурсы

14 автоматических тестов HTTPS/API: авторизация, cookie, Origin/Host/CSRF, домашняя подсеть, ограничение попыток входа и размера запроса, завершение сессии, безопасные команды, импорт и временные файлы, восстановление, фильтрация секретов, смена пароля. NDMS/движок имитируются. Браузерный тест в Edge проверил вход, обзор, импорт, восстановление, RU/EN, мобильную ширину 390 px и выход без ошибок JavaScript. HTTPS отдельно проверен настоящим TLS-соединением в тестах; браузерный макет использовал локальный тестовый HTTP.

Панель держит один Python-процесс постоянно, максимум 8 одновременных обработчиков; это дополнительный расход памяти. Цифры RSS/CPU на NC-1012 **ещё не измерены**, лёгкость по сравнению с конкретными приложениями не заявляется. Проверить после установки:

```sh
p=$(cat /var/run/awg3/web.pid)
grep -E '^(Name|VmRSS|VmHWM|Threads):' /proc/$p/status
```

Браузер опрашивает состояние раз в 15 секунд только на видимой вкладке. CDN, аналитики и внешних ресурсов нет. Backend выполняется от root ради управления VPN; наружу доступны только фиксированные действия, без shell и произвольных команд. Пароль хранится как PBKDF2-SHA256 с солью, 600000 итераций; cookie HttpOnly/Secure/SameSite=Strict, CSRF-токен, проверка Host/Origin, TLS 1.2+. Это не заявление об отдельном внешнем аудите безопасности.
